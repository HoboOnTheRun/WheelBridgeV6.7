# WheelBridge

I made WheelBridge so I could use my steering wheel, pedals and other sim gear in games that don’t normally support them.

It works by turning your wheel inputs into a **virtual Xbox controller**, letting the game recognise steering, throttle, brakes and buttons as controller inputs.

## Features

- Map your wheel, pedals and accessories to Xbox controls.
- Save different settings for each game.
- Add adjustable centring resistance for games such as GTA V.
- Use the included **Over the Hill mod** for feedback based on vehicle physics, including tyre forces, bumps and collision shudder.

## Getting started

1. Download the **Friends ZIP** from the Releases section and extract it.
2. Open WheelBridge and install the included virtual-controller driver if needed.
3. Select your devices and calibrate your controls.
4. Choose your game and click **Start controller**.
5. Keep WheelBridge running while you play.

For Over the Hill feedback, close the game and run **Install-OverTheHill.cmd** first. Then start the game and enable feedback in WheelBridge.

## A few things to know

- Run only one copy of WheelBridge at a time.
- Start with a low feedback strength and adjust it to suit your wheel.
- Each person needs to calibrate their own setup.
- Game compatibility varies. Most games use manual centring; live vehicle feedback currently requires the Over the Hill companion mod.
- This is still a work in progress. Basic feedback has been tested on a Thrustmaster T300RS, while collision effects and full multiplayer compatibility need more testing.

**Emergency feedback off:** `Ctrl + Alt + Backspace`
